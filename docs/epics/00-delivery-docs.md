# E00 Delivery docs

Milestone: M1 Foundations. Depends on: nothing.

## Goal

Write the plan down in the repository so any session can pick up the work, verify what is done and
continue with the next epic.

## Tasks

- [x] T1 `docs/ROADMAP.md`: decisions, architecture, testing layers, CI, epic index.
- [x] T2 One file per epic under `docs/epics/` with goal, tasks, fixtures, acceptance criteria and
  dependencies.
- [x] T3 `docs/RISKS.md` with impact, likelihood and mitigation per risk.
- [x] T4 `docs/DELIVERY_STATUS.md` with the gate commands and the epic table.

## Acceptance criteria

1. Every epic listed in the roadmap has a file with testable acceptance criteria.
2. No document uses the em dash character.

## Implementation notes

Written by hand before the first epic-runner session, since the runner needs a plan to exist.
