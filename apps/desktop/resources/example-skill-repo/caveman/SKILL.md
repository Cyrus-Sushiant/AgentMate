# Caveman

Caveman is maintained upstream at https://caveman.so/ and https://github.com/JuliusBrussee/caveman.
Run the official installer to add it to this project's agent:

```bash
curl -fsSL https://raw.githubusercontent.com/JuliusBrussee/caveman/main/install.sh | bash
```

This pulls the current skill files directly from the source repo, so it always installs the
latest version instead of a copy pinned to this marketplace entry.
